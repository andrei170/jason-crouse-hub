Tech Stack (recommended, swappable)

  • Site host: Squarespace (existing - keep) for saintsofflow.com main; custom HTML hosted on subdomain for landing pages that need control
  • Course / Tripwire host: Kajabi (preferred for solo coach simplicity) or Teachable
  • Email: Kit / ConvertKit (preferred for personal-development audiences) or Kajabi-native
  • Replay countdown: Deadline Funnel (preferred) or evergreen-launching plugin
  • Payment: Stripe (Self Phase) + bank wire / Stripe Invoice (Inner Circle high-ticket)
  • Video host: Wistia (replay + tripwire) + YouTube (long-form) + Loom (1:1 voice messages for Inner Circle)
  • Analytics: GA4 + Meta Pixel + Microsoft Clarity (heatmaps)
  • CRM: GHL (preferred for cohort fill) or Kajabi-native
  • Community / Inner Circle: Slack or Telegram (Inner Circle private channel) + existing community for Flow Code
  • Scheduling: Calendly (default) for Inner Circle 1:1 calls
  • Project / build: Notion (handover-friendly) + Linear (engineering)

Integration Points

  1. Replay opt-in → Email · landing-page form triggers Kit on submit, kicks off 5-touch countdown sequence
  2. Email → Application · Kit triggers route to Flow Code application form on day 5 of sequence
  3. Email → Self Phase · non-applicants on day 6 routed to Self Phase tripwire landing
  4. Self Phase purchase → Email · Stripe webhook triggers Kit "Self Phase graduate" tag for 6-month re-target
  5. Flow Code graduation → Inner Circle invitation · Kajabi or GHL completion event triggers private Inner Circle invitation email
  6. Live webinar (next quarterly cadence) → Recording → New evergreen replay
  7. All events → GA4 + Meta Pixel via GTM

Owner Map

  • Jason: filming the live webinar (May 13 + quarterly thereafter), Inner Circle 1:1 calls and group coaching, Self Phase optional group call (if $197 tier), top-line decisions on copy + brand
  • AG1 (Andrei): everything else - replay funnel build, Self Phase landing + checkout, Inner Circle landing + application, email sequences, automation setup, ad management, weekly reporting

Failure Modes + Mitigations

  • May 13 recording quality issues → backup recording on second device + Riverside cloud capture; AG1 owns post-production
  • Squarespace landing-page constraints → if Squarespace can't host the replay countdown cleanly, deploy custom HTML on a subdomain (e.g. replay.saintsofflow.com)
  • Inner Circle first-cohort fill below 6 → run a 90-day "founding members" pricing window for graduates who book by a soft deadline; minimum cohort = 4
  • Self Phase content cannibalising Flow Code → tripwire stays at 5 weeks of Self only; Love and Lead phases stay program-exclusive

KPIs (90-day)

  • Phase 1 · Big Three Mastery replay funnel live · 200+ opt-ins in first 30 days
  • Phase 2 · Self Phase tripwire converting at 5-15% of replay non-applicants · Inner Circle interest list at 25+ graduates
  • Phase 3 · 40+ short-form posts shipped · 6 long-form podcast episodes published
  • Phase 4 · Meta CPL under $30 · ROAS 3x by week 12
  • Year-1 floor target · $260,000-$530,000 incremental on top of existing Flow Code revenue
